# my-best-cities

Це маленький веб-проект про три улюблені міста.

## Структура

- `index.html` — головна сторінка
- `city-1.html` — сторінка про Київ
- `city-2.html` — сторінка про Львів
- `city-3.html` — сторінка про Одесу
- `form.html` — форма для зворотного зв’язку
- `images/` — папка з зображеннями

## Як відкрити

Відкрийте `index.html` у браузері.
