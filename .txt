4. Постановка задачі
Створити односторінковий веб сайт компанії «Акустична варта» — сервісу професійного моніторингу шумового забруднення міських територій. Сторінка має показувати результати вимірювань, напрямки роботи, попередження та форму замовлення дослідження.
JavaScript і CSS-фреймворки в цій лабораторній не використовуються.
5. Опис предметної області
«Акустична варта» встановлює тимчасові акустичні датчики, проводить вимірювання рівня шуму та формує звіти для житлових комплексів, офісних центрів, підприємств, міських просторів та організаторів масових заходів.
Предметна область дозволяє природно використати інформаційні картки, попередження, показники моніторингу, журнал вимірювань і форму.
6. Структура майбутньої сторінки
<body>
├── <header> -- назва, слоган, <nav>
├── <main>
│   ├── <section> -- вступ
│   ├── <section> -- поточний моніторинг
│   ├── <section> -- напрямки роботи
│   │   └── <article>
│   ├── <aside> -- попередження
│   ├── <section> -- останні вимірювання
│   └── <section> -- форма замовлення
└── <footer>

7. Вимоги до HTML
Використати header, nav, main, section, article, aside та footer там, де вони семантично доречні.
Вступний блок: заголовок і 1–2 абзаци.
Поточний моніторинг: об’єкт, статус, середній рівень, період, кількість точок.
Напрями роботи: 3–4 article-картки.
Попередження: окремий aside.
Останні вимірювання: дата, місце, рівень, статус.
Форма: ім’я, email, тип об’єкта, період, опис, кнопка.
Footer: назва, контакти, рік.
8. Вимоги до CSS
Створити css/style.css та підключити його через link.
Використати селектори елемента, класу, id, атрибута та універсальний селектор.
Використати групування селекторів.
Продемонструвати width, height, margin, padding, border, color, background, font-size та display.
Для карток використати спільний клас і display: inline-block.
Не використовувати Bootstrap, Tailwind CSS або готовий CSS-шаблон.
9. Покрокове виконання
Етап 1. Підготовка проекту
Створіть lab-2/index.html, css/style.css та images/.
Етап 2. HTML-структура
Створіть семантичну структуру header → main → секції → footer.
Етап 3. Контент
Наповніть сторінку реалістичними даними про акустичний моніторинг.
Етап 4. Підключення CSS
Підключити зовнішню таблицю стилів.
Етап 5. Базова стилізація
Оформіть body, заголовки, текст, секції та основні блоки.
Етап 6. Селектори
Застосуйте різні типи селекторів до реальних елементів.
Етап 7. Box Model
Налаштуйте розміри, внутрішні та зовнішні відступи, рамки.
Етап 8. display
Продемонструйте block та inline-block.
10. Перевірка результату
HTML має коректну семантичну структуру.
CSS підключений із зовнішнього файлу.
Використані різні типи селекторів.
Є реальний приклад каскаду та specificity.
Застосовано margin, padding, border, width і height.
Продемонстровано display: inline-block.
Класи названі за призначенням.
Немає зайвого дублювання CSS.
Сторінка перевірена у браузері та DevTools.
Для картки вимірювання застосувати Box Model та box-sizing: border-box.
Для warning використати position: relative, а для маленької позначки статусу — position: absolute.
Для кнопки та карток додати transition, щоб зміна стилю відбувалася плавно.
Для декоративного елемента датчика використати transform: translate(), rotate() або scale().
На сторінці має бути щонайменше один приклад навмисного конфлікту CSS-правил для аналізу cascade та specificity.
Не використовувати JavaScript: інтерактивність hover реалізуються тільки CSS.
При наведенні кнопка змінює колір.
